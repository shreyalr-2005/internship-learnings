1.What is the use of Venv?
    “venv is used to create an isolated environment for each project so that project dependencies (libraries) do not conflict with each other.”

2.How to see what are the libraries installed?
     pip list

3.How to tell if the libraries are installed globally or locally
     We can check the terminal prompt. If the virtual environment is active (shown as(venv)), libraries are local. Otherwise, they are global.
